# 정지안 · 퍼포먼스 마케터 포트폴리오

광고 운영, 크리에이티브 실험, 전환 흐름 개선, AI를 활용한 업무 시스템 구축 경험을 정리한 포트폴리오입니다.

## 업데이트

- 현재 재직: 리터니티 · 미국·일본 퍼포먼스 마케팅
- 일본 싱글원 큐텐 메가와리 참여
- S.07: AI를 활용한 미국 광고 분석 도구와 일본 큐텐 웹 운영 콘솔 구축 과정
- 기존 디자인과 여섯 가지 사례 유지

## AI 업무 시스템 사례

업무 문제와 판단 기준을 정의하고, AI의 도움으로 구현한 뒤 결과와 예외 조건을 검토했습니다.

- 소재별 지출, 집행 기간, 구매 표본에 따른 검토 기준
- 중단·유지·확장 검토 및 데이터 부족 분류
- 일별 구매 흐름과 인하우스·대행사 성과 구분
- 운영 중인 광고 상태와 최신 데이터 선택 로직 반영
- 일본 큐텐 콘솔: 예산·성과 요약, 지표 전환, 액션 시점과 일별 추이 확인
- 소재별 진단과 담당자 메모를 통한 다음 수정 가설 정리

[프로젝트 소스와 구현 기록](https://github.com/ejj1220b-design/project)

## 구성

`index.html`과 이미지 파일로 구성된 정적 웹사이트입니다. 별도 설치 없이 열 수 있으며 GitHub Pages의 `main` 브랜치 루트에서 배포합니다.

이 저장소는 [기존 포트폴리오](https://github.com/ejj1220b-design/marketing)의 복제본입니다. 원본은 유지됩니다. 포함된 `resume_jian.pdf`는 이전 이력서이며 현재 경력은 웹페이지를 참고해 주세요.

## 업무 자료 이미지

실제 웹 업무 화면을 기반으로 한 공개용 편집본 3장을 포함합니다. 예산·성과 수치·소재명 등 내부 정보를 가렸습니다.

- `returnity-console-public.png`: 일본 싱글원 큐텐 보고 보드
- `returnity-diagnosis-public.png`: 소재별 진단과 담당자 메모
- `returnity-flow-public.png`: 지표 전환과 액션 시점별 추이 확인

미국 광고 분석 도구와 일본 큐텐 운영 콘솔은 별도 업무 도구입니다. 화면의 그래프를 성과 개선의 증거로 제시하지 않습니다.
